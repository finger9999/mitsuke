## MCP 서버 (5단계)

맥 앱이 사람용 화면이라면 MCP 서버는 AI 에이전트용 인터페이스다. 같은 SQLite DB 위에 얹기만 하고 파이프라인 로직은 건드리지 않는다.

- MCP Python SDK 2.x (`mcp` 2.3). 1.x의 `FastMCP`가 2.x에서 `MCPServer`(`mcp.server.mcpserver`)로 이름이 바뀌어 있었다. 처음에 1.x 방식으로 import했다가 에러 메시지를 보고 알았다.
- 도구 10개. 읽기 도구는 `read_only_hint`, 쓰기 도구는 `idempotent_hint` 표시.

| 도구 | 하는 일 |
| --- | --- |
| `get_new_matches(min_score, hours, limit)` | 최근 고득점 매물 (👎 제외) |
| `search_listings(query)` | 제목으로 찾기 |
| `give_feedback(listing_id, value)` | 👍👎 기록 |
| `get_taste` / `set_taste` | 취향 기준 보기·고치기 |
| `get_taste_history` | 자동 개선 기록 |
| `list_searches` / `add_search` / `set_search_enabled` | 검색어 관리 |
| `get_status` | 마지막 실행, 이번 달 비용, 매물·피드백 수 |

- 서버 안내문(instructions)에 "피드백은 사용자의 취향 정답이니 사용자가 원할 때만 기록", "결제는 대신하지 않는다"를 넣었다.
- 저장소 루트 `.mcp.json`에 등록해서, 이 폴더에서 Claude Code를 열면 승인 후 바로 쓸 수 있다.
- 확인: 도구 목록 조회와 호출(서버 객체 직접), stdio `initialize` 응답.

## 취향 기준 자동 개선 (6단계)

`python main.py tune [--dry-run] [--sample 40] [--margin 0.03]`

1. 라벨 매물을 매물 ID 해시로 **제안용 / 검증용** 반반 나눈다 (실행마다 같은 분할).
2. 제안용에서 AI와 사용자가 어긋난 매물(60점 이상인데 👎 / 90점 미만인데 👍, 각 최대 8개)을 사진·제목·AI 이유와 함께 Gemini에 보여주고 취향 기준을 고쳐 쓰게 한다. "무조건 조건은 강한 근거 없이 지우지 말 것", "브랜드로 판단하지 말 것", "매물 하나에만 맞춘 규칙 금지"를 지시했다.
3. 검증용(👍 전부 + 👎 무작위, 총 40개)을 지금 기준과 제안 기준으로 각각 채점한다.
4. **분리도(AUC)가 0.03 이상 오를 때만 반영**. 결과와 무관하게 `settings.taste_history`(최근 20개)와 보고서를 남긴다.

평가 지표(`auc`, `metrics`)는 `finder/metrics.py`로 옮겨 평가 스크립트와 같이 쓴다.

### 첫 실행 결과

첫 시도는 제안 단계에서 Gemini 503(과부하)으로 실패했다. 튜너의 Gemini 클라이언트에는 채점기에 넣은 재시도 설정이 빠져 있었다 → 재시도 5번, 실패하면 "취향 기준은 그대로"라고 알리고 끝나게 고쳤다.

두 번째 시도:

| 기준 | 분리도(AUC) | 👍 평균 | 👎 평균 | 90점 정밀도 | 90점 재현율 |
| --- | --- | --- | --- | --- | --- |
| 지금 기준 | 0.696 | 72 | 59 | 67% | 57% |
| 제안 기준 | 0.717 | 65 | 48 | 60% | 43% |

**반영 안 함.** 분리도는 +0.021로 기준(+0.03)에 못 미쳤고, 알림 쪽 정밀도·재현율은 오히려 떨어졌다. 검증용 👍가 7개뿐이라 숫자 자체가 크게 흔들린다.

제안이 짚은 경향은 사용자에게 확인할 가치가 있다.

- "울 소재에 집착하지 않는다" → 울 필수 조건을 빼자고 했다. 지시("무조건 조건은 강한 근거 없이 지우지 말 것")를 어긴 제안이다. 👍한 매물 중 울이 아닌 것들이 근거였을 것이다.
- [싫어하는 것] 칸 추가: 정석적인 비즈니스 느낌의 클래식 코트(빅 카라, 더블 버튼), 어깨 패드, 패딩.
- 실험적이고 독창적인 컷팅·배색·실루엣을 선호.

자동 반영은 안 됐지만, 사용자가 맞다고 하는 부분만 골라 직접 취향 기준에 넣을 수 있다.
