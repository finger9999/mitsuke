# 007. 채점 LLM을 Gemini로 바꿈

2026-11-14 · 관련 파일: [finder/scorer.py](../../finder/scorer.py), [config.yaml](../../config.yaml)

## 결정

사용자가 API 키를 Gemini로 쓰겠다고 했다. 005에서 Claude Haiku 5.5로 만든 채점기를 Google Gemini로 바꿨다. 파이프라인, 비용 상한, 아우터만 채점하는 구조는 그대로다.

## 모델 고르기

Google 공식 가격표(2026-11-14 확인)에서 이미지 입력을 받고 무료 등급이 있는 싼 모델:

| 모델 | 유료 가격 (입력 / 출력, 100만 토큰당) | 비고 |
| --- | --- | --- |
| `gemini-2.5-flash-lite` | $0.10 / $0.40 | 가장 쌈. 같은 2.5 세대의 flash·pro는 이미 지원 중단(deprecated) 공지 |
| **`gemini-3.1-flash-lite`** (기본) | $0.25 / $1.50 | 현행 세대 |

둘 다 **무료 등급**이 있다. 지금 물량(채점 대상이 하루 몇 개)이면 무료 등급 안에서 끝날 가능성이 높다. 2.5 세대가 정리되는 중이라 기본값은 3.1 flash-lite로 하고, `config.yaml`의 `gemini_model`로 2.5 flash-lite를 고를 수 있게 했다.

무료 등급 데이터는 Google이 제품 개선에 쓸 수 있다는 조건이 붙는다. 매물 사진·제목·취향 기준 정도라 문제는 적다고 봤다.

## Claude 버전과 달라진 점

| | Claude (005) | Gemini (지금) |
| --- | --- | --- |
| SDK | `anthropic` | `google-genai` |
| 사진 | URL을 그대로 넘김 | URL을 못 받아서 썸네일(7KB)을 받아 바이트로 넘김 |
| JSON 출력 | `output_config.format` | `response_mime_type` + `response_json_schema` |
| 생각 줄이기 | `effort: low` | `thinking_level: MINIMAL` (모델이 거부하면 설정 없이 재시도) |
| 비용 계산 | 입력·출력 토큰 | 입력 + 출력 + 생각 토큰. 유료 가격 기준이라 무료 등급이면 실제 청구는 0 |
| 키 | 키체인 `mitsuke-anthropic` | 키체인 `mitsuke-gemini` / `GEMINI_API_KEY` |

## 확인 상태

- 단위 테스트는 가짜 채점기를 써서 그대로 통과.
- 실제 Gemini 호출은 키를 넣은 뒤 `reevaluate`로 확인한다.

## 겪은 것: 키를 넣었더니 402

키를 키체인에 넣고 `reevaluate`를 돌리자 아우터 10개 모두 이렇게 실패했다.

```
402 RESOURCE_EXHAUSTED: Your prepayment credits are depleted.
```

키 자체는 받아들여졌다. 사용자의 AI Studio 프로젝트가 **선불(prepay) 결제** 방식이고 충전된 크레딧이 0이라서 생긴 오류다. 무료 등급이 적용되지 않은 것으로 보아, 선불 결제를 켠 프로젝트는 무료 등급 대신 크레딧에서 차감되는 것으로 추정한다 (확인 필요).

같은 오류로 10번을 연달아 호출한 것도 문제였다. 키·결제·한도 오류(401/402/403/429)는 다음 매물에서도 똑같이 실패하므로, 한 번 나면 **그 실행에서는 채점을 멈추고** 남은 매물은 "채점 중단: API 선불 크레딧 소진"으로 목록에만 올리게 바꿨다. 점수 없는 통과 매물은 나중에 `reevaluate`로 다시 채점할 수 있다.

## 해결과 첫 채점 결과

사용자가 결제 연결 없는 프로젝트(무료 등급)로 바꾼 뒤 `reevaluate`를 다시 돌리자 정상 동작했다.

- 채점 13개 (점수 없는 통과 매물 중 아우터만), 나머지 58개는 아우터가 아니라 채점 없이 목록에
- 비용: 유료 가격 기준 추정 매물당 약 $0.0005, 13개 합계 $0.007. 무료 등급이라 실제 청구는 없다. 005의 추정(1원 안팎)과 맞았다.
- 90점 이상은 0개 → 알림 대상 없음

| 점수 | 매물 | 이유 (요약) |
| --- | --- | --- |
| 85 | センソユニコ チェック テーラードジャケット ウール | 제목에 울이 있지만 테일러드 재킷이고 성분표는 불명확 |
| 75 | センソユニコ ダウンジャケット | 울 혼방이지만 패딩이라 숏코트가 아님 |
| 50 | ツモリチサト ダブルボタンショートコート | 디자인·기장은 맞지만 면 100%라 울 조건 불충족 |
| 25 | センソユニコ ダウンコート | 나일론 패딩 |

"울 무조건" 조건을 엄격하게 지켰다. 설명에서 소재(면 100%, 나일론)를 읽어 낸 경우가 많아서 판매자 설명을 같이 넘긴 효과가 있었다. 사용자가 처음 "예쁘다"고 한 숏코트(ツモリチサト ダブルボタン)는 면이라 50점이 나왔다. 조건 밖이어도 마음에 들면 👍로 알려주면 다음 채점부터 예시로 반영된다.
