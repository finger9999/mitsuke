# 013. 알림이 조용히 꺼져 있었다

2026-11-15 · 관련 파일: [scripts/build_app.sh](../../scripts/build_app.sh), [app/Mitsuke/Sources/Mitsuke/AppModel.swift](../../app/Mitsuke/Sources/Mitsuke/AppModel.swift)

## 발견

다음 할 일을 정리하기 전에 밤사이 로그를 봤더니, 90점 이상 새 매물 **16개**의 알림이 전부 실패해 있었다.

```
ERROR finder.notifier: 알림 실패 mercari:m51184883305: 알림 권한 없음: Notifications are not allowed for this application
```

사용자는 알림을 허용했고, 알림을 누르면 Buyee가 열리는 것도 확인했었다. 그런데도 실패했다.

## 원인

`~/Library/Preferences/com.apple.ncprefs.plist`의 앱별 `flags`(002에서 찾은 "알림 허용" 비트 `0x2000000`):

| 번들 ID | flags | 허용 비트 |
| --- | --- | --- |
| `com.mitsuke.notifier` (예전 알림 앱) | `0x1280200E` | 켜짐 |
| `com.mitsuke.app` (지금 앱) | `0x1080200E` | **꺼짐** |

지금 앱은 알림이 꺼져 있다. 추정 원인은 두 가지다 (어느 쪽인지 확정하지 못함).

1. 허용을 예전 알림 앱 쪽에 했다.
2. **다시 빌드할 때마다 권한이 풀린다.** 앱을 애드혹 서명(`codesign -s -`)하고 있었는데, 애드혹 서명은 빌드할 때마다 서명 해시가 바뀐다. macOS가 이걸 다른 앱으로 볼 수 있다. 어제 앱을 여러 번 다시 빌드했다 (👎 숨기기, 20점 미만 숨기기, 사진 캐시).

또 하나의 구조적 문제: 알림은 launchd가 부르는 `--notify` 모드에서 보내는데, 이 모드에서는 허용 창이 뜨지 않는다. 권한이 없으면 화면에 아무 표시 없이 로그에만 남는다.

## 고친 것

1. **Apple Development 인증서로 서명.** 이 맥에 Xcode가 만든 `Apple Development` 인증서가 있어서, 빌드 스크립트가 있으면 그걸로 서명하게 했다. 다시 빌드해도 같은 팀·같은 앱으로 인식된다. 인증서가 없으면 예전처럼 애드혹 서명하고 경고를 찍는다.
2. **앱이 알림 권한을 직접 확인한다.** 앱(화면 모드)이 켜질 때 권한이 "아직 안 정함"이면 허용 창을 띄우고, 30초마다 상태를 확인한다. 꺼져 있으면 메뉴바 창과 매물 창 위에 "알림이 꺼져 있어요 · 알림 설정 열기" 경고를 띄운다. 이제 조용히 실패하지 않는다.

## 함께 보인 것: 알림이 꽤 많다

어제 저녁 몇 시간 동안 90점 이상 새 매물이 16개 나왔다. 대부분 울 숏코트 검색에서다. 012 평가에서 90점 기준 정밀도가 50%였으니, 알림의 절반쯤은 마음에 안 드는 매물일 수 있다. 알림이 켜진 뒤 실제로 얼마나 오는지 보고 기준 점수를 조정한다.
