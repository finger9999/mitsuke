# 010. 브랜드가 아니라 디자인으로 채점하기

2026-11-14 · 관련 파일: [finder/scorer.py](../../finder/scorer.py), [finder/pipeline.py](../../finder/pipeline.py), [finder/store.py](../../finder/store.py)

## 문제

사용자: "좋아하는 디자인의 코트여도 츠모리 치사토나 센소유니코가 아니라서 점수를 낮게 줬는데, 안 그래도 된다. 나는 디자인만 본다."

원인은 두 군데였다.

1. **채점 규칙(시스템 프롬프트)**: 처음 두 브랜드만 검색할 때 써 둔 "30~59: 브랜드는 맞지만 관심 밖", "0~29: 검색한 브랜드의 상품이 아니다"가 그대로 남아 있었다. 브랜드 없는 울 숏코트 검색(009)을 추가하면서 이 규칙이 다른 브랜드를 깎는 쪽으로 작동했다.
2. **취향 기준**: [관심 있는 것]이 "두 브랜드 특유의 디자인"으로 적혀 있었다.

## 고친 것

- 점수 구간을 브랜드가 아니라 디자인 기준으로 다시 썼다.
  - 30~59: 디자인이 취향과 거리가 있다
  - 0~29: 취향과 정반대이거나 옷·소품이 아니다 (빈 상자, 쇼핑백 등)
- 규칙 추가: "사용자는 디자인만 본다. 브랜드 이름으로 점수를 더하거나 빼지 않는다. 무명이어도 디자인으로만 판단한다."
- 채점할 때 **검색어를 넘기지 않는다.** 검색어가 브랜드명이라 AI가 "이 브랜드를 찾는구나"로 읽었다.
- 취향 기준: [관심 있는 것]을 "디자인이 마음에 드는 옷과 소품, 종류·브랜드 상관없음. ツモリチサト·センソユニコ 같은 디자인 감성을 좋아한다 (브랜드 이름이 아니라 그 디자인)"으로 바꿨다. 두 브랜드는 감성의 예시로만 남겼다.

## 같이 고친 것: 점수 못 받은 매물 자동 재시도

울 숏코트 검색이 시간당 20개쯤이라 실행당 채점 상한(30개)에 자주 걸리고, Gemini 일시 오류(503)도 가끔 난다. 지금까지는 이런 매물이 점수 없이 남아서 `reevaluate`를 손으로 돌려야 했다.

- 매 실행 끝에, 지난 48시간 안에 들어왔는데 점수를 못 받은 매물(상한 초과·API 오류·채점 중단)을 남은 상한 안에서 다시 채점한다.
- 검색어 첫 실행 때 이미 있던 매물인지(`baseline` 컬럼)를 기록해서, 재시도로 90점이 나와도 그런 매물은 알림을 보내지 않는다. 새로 올라온 매물은 재시도에서 90점이 나오면 알림을 보낸다.
- 채점 대상이 아니라서 건너뛴 매물(score_reason이 비어 있음)은 재시도하지 않는다.

## 범위에서 뺀 것

- **원화 예상 가격 (`pricing.py`)**: 사용자 결정으로 뺐다. 설계 문서 1단계와 6단계의 가격 계산·배송비 보정은 하지 않는다.
- **로그인 시 자동 실행, 앱 아이콘**: 지금은 필요 없다.
- 알림을 누르면 Buyee가 열리는 것(합친 앱 기준)은 사용자가 확인했다.

## 결과

새 규칙으로 129개를 다시 채점했다 (유료 가격 기준 $0.28, 무료 등급이라 실제 청구 없음. 7개는 Gemini 503 일시 오류, 1개는 팔린 매물 → 자동 재시도 대상).

| | 바꾸기 전 평균 | 바꾼 뒤 평균 |
| --- | --- | --- |
| 울 숏코트 검색 (브랜드 없음) 38개 | 44 | **58** |
| 브랜드 검색 79개 | 41 | 42 |
| 사용자가 👍한 7개 | 59 | **69** |
| 사용자가 👎한 66개 | 37 | 41 |

- 다른 브랜드 코트가 제 점수를 받기 시작했다. 예: Nîmes 울 숏코트 25 → 95, イノウェーブ 울 혼방 숏코트 20 → 90.
- 👍와 👎의 평균 차이가 22점 → 28점으로 벌어졌다. 008에서는 👍가 3개라 효과가 없었는데, 👍가 7개로 늘면서 사진 비교도 작동하는 것으로 보인다. 점수 이유에 "참고한 ANAYI 코트와 유사", "둥근 깃·앵커 단추" 같은 디테일 비교가 나오기 시작했다.
- 이유에 "브랜드"가 나오는 경우가 129개 중 19개 남았다. 대부분 "브랜드 특유의 디자인" 같은 표현으로, 감점 근거로 쓰인 건지는 따로 확인하지 않았다.
- 90점 이상 6개. 다시 평가라 알림은 보내지 않았다.

표본이 작고 같은 매물로 전후를 비교한 것이라 정확도를 증명한 건 아니다. 제대로 된 측정은 3단계 평가 하네스에서 한다.
